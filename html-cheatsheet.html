HTML 标签速查表

按「这个标签是干什么的」组织，不按字母排。看懂一列「什么时候用」比背标签名有用得多。

1页面骨架（每个文件都长这样）

标签中文含义什么时候用 / 记忆点
<!DOCTYPE html>文档类型声明第一行必须有，告诉浏览器"这是现代 HTML5"。不是标签，不用闭合。
<html>整个网页最外层容器，里面只放 head 和 body 两个儿子。
<head>页面设置区（给人看不见）放标题、编码、CSS 引用。这里的字不会显示在网页上。
<body>页面内容区（给人看）所有你能在浏览器里看到的东西都放这里。
<meta charset="UTF-8">字符编码声明不写这句，中文会变乱码。放在 head 第一行。
<meta name="viewport" ...>手机屏幕适配声明不写这句，手机打开会缩小成一小块。现在建站必写。
<title>浏览器标签页上的标题不是页面里的大标题！它是标签页和搜索结果里显示的名字。

2标题与段落（内容的骨架）

标签中文含义什么时候用 / 记忆点
<h1>…<h6>一级到六级标题h1 是页面主题，一篇只用一个；h2 是大章节，h3 是小节。按层级用，别为了字大跳级。
<p>段落一段话用一个 p。p 不能套 p。
<br>强制换行同一段里硬换行（地址、诗句）。不要用它代替段落间距。
<hr>分隔线话题切换时画一条横线。空标签，不用闭合。
<strong>重要（语义上强调）比 <b> 更好：它告诉搜索引擎"这很重要"，不只是变粗。
<em>强调（语气加重）比 <i> 更好，表示"读的时候要重读"，默认显示斜体。
<blockquote>引用一段话引用别人原文，默认会缩进。里面还要再套 p。

3列表（三种，别混用）

标签中文含义什么时候用 / 记忆点
<ul> + <li>无序列表（圆点）顺序不重要时：菜单、特点清单、友情链接。
<ol> + <li>有序列表（1234）顺序有意义时：操作步骤、排行榜。ol 是 ordered 的首字母。
<dl> / <dt> / <dd>名词解释列表术语表、问答。dt 是词，dd 是解释，正好适合你那张 GitHub 术语表。

4链接与图片

标签 / 属性中文含义什么时候用 / 记忆点
<a href="…">超链接（a = anchor 锚）跳到别的页面。站内用相对路径 about.html，站外用 https://…。
target="_blank"在新标签页打开外链建议加，别把访客从你的站带走。
<img src="…" alt="…">插入图片alt 必须写：图片加载失败时显示这段文字，也是给视障用户读屏用的。
width / height宽高（像素）写上能防止图片加载时页面跳动。
路径三句话记住：logo.png = 同一文件夹里的文件；images/logo.png = 子文件夹里；../logo.png = 上一级文件夹里（两个点 = 往上走一层）。

5语义标签（HTML5 重点，也是"含义"的真正来源）

这些标签外观跟 <div> 几乎一样，但名字本身表达了"这块内容是什么"。搜索引擎和读屏软件靠它们理解你的页面。

标签中文含义什么时候用 / 记忆点
<header>页头 / 区块头部放 logo、站名、导航。可以有好几个（每个 section 都能有）。
<nav>导航区主要链接集合。不是所有链接都算导航，页脚的零散链接不算。
<main>主要内容区一页只能用一次，装这页真正的内容。CSS 里常配合居中和宽度。
<article>独立成篇的内容一篇文章、一条博客、一个卡片。判断标准：单独拿出去也讲得通。
<section>有主题的区块通常带一个小标题。没标题的纯布局就别用它，用 div。
<aside>侧边 / 补充内容相关推荐、作者简介、广告位。删掉它不影响主内容。
<footer>页脚版权、联系方式、备案号。
<div>通用容器（无语义）纯粹为了布局分组，没有更合适的语义标签时才用。它是最后的选择，不是第一选择。

6表格（数据才用，别拿来排版）

标签中文含义什么时候用 / 记忆点
<table>表格展示"行列对应"的数据。拿来摆版面是二十年前的做法。
<tr>表格的一行（row）先写 tr，再往里面塞格子。
<th>表头单元格默认加粗居中，语义上表示"这一列是什么"。
<td>普通数据单元格td = table data。
colspan / rowspan跨列 / 跨行合并合并单元格用，写数字表示跨几格。

7表单（要收集用户输入时才用）

标签中文含义什么时候用 / 记忆点
<form>表单容器包住一组输入。静态站没有后台，提交需要外部服务配合。
<input>输入框（万能选手）type 决定长相：text 文本、email 邮箱、password 密码、checkbox 勾选、radio 单选、file 选文件。
<label>输入框的说明文字点了文字就能聚焦输入框，手机上也更好点。别忘了写。
<textarea>多行文本框留言、评论。跟 input 不同，它有闭合标签。
<button>按钮比 <input type="submit"> 更灵活，里面能放图标和文字。
<select> + <option>下拉选择框选项固定且不多时。

8最容易搞混的几对

<b> vs <strong>外观一样。b 只是变粗（样式），strong 表示"重要"（语义）。优先 strong。
<i> vs <em>外观一样。i 只是斜体，em 表示"语气强调"。优先 em。
<div> vs <section>div 是纯容器；section 表示"这一块有主题"。有标题用 section，纯布局用 div。
<head> vs <header>head 是页面设置区（看不见），header 是页头（看得见）。差一个字母，天差地别。
class vs idclass 可以重复用（多个元素共用一套样式）；id 全页唯一（当锚点、被 JS 找）。
相对路径 vs 绝对路径a.html 跟着文件夹走；/a.html 从网站根目录算；https://… 完整地址。

9空标签（不用闭合的五个）

标签作用
<br>换行
<hr>分隔线
<img>图片
<input>输入框
<meta> / <link>页面设置 / 引入外部文件（如 CSS）
在 VS Code 里怎么查语义：把光标放在任意标签上按 F1 搜 "hover"，或者直接把鼠标停上去——会弹出英文官方说明。看不懂英文时，回这张表查，两边对照着记，一个月就熟了。
